# Python-projects

A small Python collection of fun and useful programs built with simple code and beginner-friendly design. This repository includes a calculator app, a countdown timer, and a Rock-Paper-Scissors game. Each program is written to be easy to understand and use.

## Projects Included

- `Calculator.py`
  - A combined command-line and GUI calculator.
  - Supports addition, subtraction, multiplication, division, power, square root, and cube root.
  - Includes a calculation history panel for recent results.

- `Countdown Timer.py`
  - A simple countdown timer with a graphical user interface.
  - Enter seconds and watch the timer count down.
  - Alerts when time is up.

- `Rock-paper-scissor-game.py`
  - A basic Rock-Paper-Scissors game with a GUI.
  - Play against the computer and track the score.
  - Includes reset and quit controls.

## Requirements

- Python 3.x
- Standard library only (no external packages required)
- For GUI programs, a desktop environment with display support is required

## How to Run

Open a terminal in the repository folder and use one of the following commands:

```bash
python "Calculator.py"
python "Countdown Timer.py"
python "Rock-paper-scissor-game.py"
```

## Notes

- `Calculator.py` can run in CLI mode when a graphical display is not available.
- `Countdown Timer.py` and `Rock-paper-scissor-game.py` require a display to launch the Tkinter window.

## Suggested Use

- Use the calculator for quick math and simple history tracking.
- Use the countdown timer for short time checks and reminders.
- Use the game for a simple interactive exercise with computer play.
